# Diseño de Oficina Pixel Art - Estilo GameBoy

Este directorio contiene el diseño del ambiente de oficina para la visualización en tiempo real de SeeControl, inspirado en el estilo pixel art de GameBoy pero con un toque cyberpunk moderno.

## 🏢 Concepto de Oficina Virtual

**Tema:** Oficinas retro-futuristas estilo cyberpunk 8-bit
**Estilo:** Pixel art isométrico simplificado (2D con perspectiva)
**Paleta:** Colores oscuros con toques neón
**Resolución:** Grid de 8x5 celdas (40x40 píxeles cada una)

## 🏗 Elementos de la Oficina

### 1. Mesas (Desks)
**Diseño:**
- Tamaño: 40x20 píxeles (ocupa 1 celda de ancho x medio de alto)
- Color base: #3A3A3A
- Borde: #2A2A2A (1 píxel)
- Sombra: #1A1A1A (1 píxel debajo)

**Sprite:**
```
┌─────────────────────┐
│                      │ 3A3A3A
│                      │ 3A3A3A
├──────────────────────┤ 2A2A2A
│                      │
└──────────────────────┘ 1A1A1A
```

### 2. Sillas (Chairs)
**Diseño:**
- Tamaño: 16x16 píxeles
- Color: #4A4A4A
- Detalle: Respaldo con línea #2A2A2A

### 3. Pantallas (Screens)
**Diseño:**
- Tamaño: 24x16 píxeles
- Marco: #2A2A2A
- Pantalla: #000000 con contenido animado
- Estado: Verde (#4CAF50) cuando activo

**Animación de Pantalla:**
```css
@keyframes screen-glitch {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.7; }
}

@keyframes screen-content {
  0% { background-position: 0 0; }
  100% { background-position: 24px 0; }
}
```

### 4. Pizarra (Whiteboard)
**Diseño:**
- Tamaño: 64x32 píxeles (2x1 celdas)
- Marco: #2A2A2A
- Fondo: #FFFFFF
- Contenido: Texto o gráficos en #000000

### 5. Planta (Plant)
**Diseño:**
- Tamaño: 16x32 píxeles
- Maceta: #8B4513 (marrón)
- Planta: #228B22 (verde)
- Detalle: Hojas pixeladas

### 6. Papelera (Trash Can)
**Diseño:**
- Tamaño: 16x16 píxeles
- Cuerpo: #808080
- Tapa: #696969

### 7. Reloj (Clock)
**Diseño:**
- Tamaño: 16x16 píxeles
- Círculo: #808080
- Manecillas: #000000
- Animación: Manecillas que se mueven

### 8. Ventana (Window)
**Diseño:**
- Tamaño: 32x32 píxeles (1x1 celda)
- Marco: #2A2A2A
- Vidrio: #00FFFF (azul claro) con efecto de cityscape
- Cortina: #1A1A1A

## 🎯 Integración con React

### Componente OfficeBackground
```tsx
interface OfficeBackgroundProps {
  theme: 'pixel' | 'cyberpunk' | 'minimal'
  width: number
  height: number
}

const OfficeBackground = ({ theme, width, height }: OfficeBackgroundProps) => {
  const themeConfig = getThemeConfig(theme)
  
  return (
    <div 
      className="office-background"
      style={{
        width: `${width * 40 + (width - 1) * 4}px`,
        height: `${height * 40 + (height - 1) * 4}px`,
        background: themeConfig.background,
        position: 'relative',
        overflow: 'hidden',
      }}
    >
      {/* Grid de celdas */}
      <div className="office-grid">
        {Array.from({ length: width * height }).map((_, index) => {
          const x = index % width
          const y = Math.floor(index / width)
          return (
            <div 
              key={index}
              className="office-cell"
              style={{
                left: `${x * 44}px`,
                top: `${y * 44}px`,
                background: getCellColor(x, y, theme),
              }}
            />
          )
        })}
      </div>
      
      {/* Elementos decorativos */}
      <OfficeDecorations theme={theme} />
    </div>
  )
}
```

## 📝 Notas de Implementación

1. **Optimización de Sprites:**
   - Usar sprite sheets para todos los elementos
   - Cargar sprites una vez y reutilizarlos
   - Usar CSS sprites para mejor performance

2. **Animaciones:**
   - Limitar a 24-30 FPS para estilo retro
   - Usar `steps()` en animaciones CSS para frames discretos
   - Evitar animaciones pesadas en móviles

3. **Responsive:**
   - Adaptar grid a diferentes tamaños de pantalla
   - Escalar sprites manteniendo proporciones
   - Ocultar elementos decorativos en pantallas pequeñas

4. **Performance:**
   - Usar `requestAnimationFrame` para animaciones JS
   - Minimizar re-renders en React
   - Usar `useMemo` y `useCallback` para funciones costosas

5. **Accesibilidad:**
   - Proporcionar texto alternativo para sprites
   - Usar colores con suficiente contraste
   - Soporte para modo oscuro

## 🔧 Herramientas para Crear Assets

1. **Aseprite** (Recomendado)
   - Editor profesional de pixel art
   - Soporte para sprite sheets
   - Paletas de colores predefinidas
   - Animaciones frame-by-frame

2. **Piskel** (Online, Gratis)
   - Editor simple y fácil de usar
   - Exportación a PNG y sprite sheets
   - Animaciones básicas

3. **Lospec Pixel Editor** (Online)
   - Editor con paletas de GameBoy
   - Herramientas de dibujo pixel perfect
   - Exportación a múltiples formatos

4. **Tiled** (Mapas)
   - Editor de mapas para el layout de la oficina
   - Soporte para capas
   - Exportación a JSON

5. **Pixel Art to CSS** (Conversión)
   - Convierte sprites a CSS
   - Genera animaciones automáticamente
