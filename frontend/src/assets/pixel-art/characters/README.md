# Catálogo de Personajes Pixel Art - Estilo GameBoy Pokémon

Este directorio contiene los sprites y animaciones de los personajes de la oficina virtual de SeeControl, inspirados en el estilo pixel art de los juegos de GameBoy (especialmente Pokémon) pero adaptados a un entorno de oficina de agentes de IA.

## 🎮 Concepto Visual

**Estilo:**
- **Resolución:** 16x16 píxeles (base) con soporte para 32x32
- **Paleta de colores:** Limitada a 4 colores por sprite (estilo GameBoy original)
- **Animaciones:** Frame-by-frame estilo 8-bit
- **Tema:** Oficinas retro-futuristas con toques cyberpunk

## 🎬 Animaciones

Cada personaje tiene 5 estados principales con animaciones de 2-4 frames:

### Estructura de Animación (CSS/JS)
```javascript
const animations = {
  idle: {
    frames: [0, 1],           // Frames 0 y 1
    speed: 2000,             // 2 segundos por ciclo
    loop: true
  },
  working: {
    frames: [0, 1, 2, 1],   // Frames 0,1,2,1
    speed: 500,              // 0.5 segundos por ciclo
    loop: true
  },
  thinking: {
    frames: [0, 1],           // Frames 0 y 1
    speed: 3000,             // 3 segundos por ciclo
    loop: true
  },
  blocked: {
    frames: [0, 1],           // Frames 0 y 1 (parpadeo)
    speed: 1000,             // 1 segundo por ciclo
    loop: true
  },
  completed: {
    frames: [0, 1, 2, 1],   // Frames 0,1,2,1
    speed: 1000,             // 1 segundo (animación única)
    loop: false
  }
}
```

## 🎯 Integración con React

```tsx
// Ejemplo de uso en componente PixelAgent
interface PixelAgentProps {
  character: 'luna' | 'max' | 'pixel' | 'data' | 'scout' | 'layout' | 'boss' | 'nex'
  status: 'idle' | 'working' | 'progress' | 'blocked' | 'completed' | 'failed'
  progress: number
  direction: 'left' | 'right' | 'up' | 'down'
}

const PixelAgent = ({ character, status, progress, direction }: PixelAgentProps) => {
  const spriteSheet = `/assets/pixel-art/characters/${character}/sprite-sheet.png`
  const animation = animations[character][status]
  
  return (
    <div className="pixel-agent" style={{ direction }}>
      <div 
        className="pixel-sprite"
        style={{
          backgroundImage: `url(${spriteSheet})`,
          animation: `${status} ${animation.speed}ms steps(${animation.frames.length}) infinite`
        }}
      />
      <div className="pixel-progress-bar">
        <div className="pixel-progress-fill" style={{ width: `${progress}%` }} />
      </div>
    </div>
  )
}
```

## 🔗 Referencias Visuales

### Estilo GameBoy Pokémon
- **Sprite Size:** 16x16 o 16x32 píxeles
- **Color Depth:** 4 colores por sprite (limitación de GameBoy)
- **Animation:** 2-4 frames por animación
- **Pixel Art Style:** Bloques de píxeles visibles, sin anti-aliasing

### Referencias de Octask
- Oficinas con vista isométrica simple
- Agentes como sprites en un grid
- Animaciones sutiles para indicar actividad
- Barra de progreso bajo cada agente

### Mejoras vs Octask
- **Más detalle:** Sprites de 16x32 en lugar de 8x8
- **Animaciones más fluidas:** 2-4 frames vs 1-2
- **Estilo GameBoy:** Paleta limitada y pixel art auténtico
- **Tema cyberpunk:** Toques futuristas en la oficina
- **Personajes únicos:** Cada uno con personalidad visual

## 🛠 Herramientas Recomendadas

1. **Aseprite** - Editor de pixel art profesional
2. **Piskel** - Editor online gratuito
3. **Lospec Pixel Editor** - Editor online con paletas
4. **Tiled** - Editor de mapas para la oficina
5. **Pixel Art to CSS** - Conversor de sprites a CSS

## 📝 Notas de Implementación

1. **Sprite Sheets:** Todos los frames de un personaje en una sola imagen para optimización
2. **CSS Sprites:** Usar background-position para mostrar el frame correcto
3. **Animación CSS:** Usar @keyframes con steps() para animación frame-by-frame
4. **React Hooks:** Usar useEffect y useState para manejar animaciones
5. **Performance:** Limitar FPS de animaciones (24-30 FPS máximo)

**Nota:** Los sprites actuales son placeholders. Para producción, se recomienda contratar a un artista de pixel art o usar herramientas como Aseprite para crear sprites profesionales.
